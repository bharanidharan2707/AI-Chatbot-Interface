# AI Chatbot Interface

## About
A simple chatbot interface built using HTML, CSS, and JavaScript. The current version responds to messages using predefined rules.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Send messages
- Display user and bot messages
- Generate predefined responses
- Send messages using the Enter key
- Clear the conversation
- Responsive chat interface

## How to Run
1. Open the project folder in VS Code.
2. Open `index.html` in a browser, or use Live Server.
3. Type a message and click **Send**.
4. Try messages about Python, HTML, CSS, or JavaScript.

## Learning Outcomes
Learn event listeners, string handling, conditional statements, DOM manipulation, and chat interface design.

## Future Improvements
Connect the chatbot to a real AI model through a backend API. Keep API keys out of browser-side JavaScript.
